# TerraSync Backend

The backend will provide the API, business logic, synchronization services, reporting services, and authentication.

## Planned Stack

- Python
- FastAPI
- Pydantic
- PostgreSQL
- Redis
- SQLAlchemy
- Docker

## Planned Services

- Authentication service
- Work order service
- Inspection template service
- Report service
- Defect service
- Sync service
- Notification service
- Export service
