# TerraSync Mobile App

The TerraSync mobile app is designed for field engineers working in low-connectivity environments.

## Planned Features

- Work orders
- Check-in / check-out
- Safety readiness
- Offline inspection templates
- Measurements
- Photo evidence
- Remarks and defects
- Local storage
- Sync status
- Report preview

## Planned Stack

- Flutter
- SQLite
- Offline queue
- Secure local storage
